# dsh-voice-message

DSH Web 语音消息插件：保留原始录音、生成本地转写，并在会话中提供可回听的语音条。

**当前状态：设计与接口预研阶段，尚无可安装的插件实现。** 目标宿主版本为 DSH `0.2.1-rc.2`，实际支持情况以接口验证结果为准。

预期流程：录音 → 保留原始音频 → 预处理副本供 ASR 转写 → 用户确认发送 → 持久化音频附件和独立转写文本 → 语音条回听。

- 仅使用 DSH 公开插件接口，不修改 core、不注入内部实现、不伪造会话事件。
- v1 使用 `file` 和 `text` block；不承诺模型能原生接收或理解音频。
- 不依赖、探测或调用其他音频分析插件。消息仅提示 agent 根据当前可用能力按需辅助理解音频，不写死插件或工具名。
- 复用宿主 Speech 服务；“本地 ASR”指在 DSH Host 上推理，远程浏览器仍需连接 Host。
- 用户显式发送，不自动发送；转写不进入普通文字草稿框，首版不提供转写校对。

实现边界、接口证据与验收见 [HANDOFF.md](HANDOFF.md)，开发纪律见 [AGENTS.md](AGENTS.md)。
