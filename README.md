# dsh-voice-message

DSH Web 语音消息插件：保留原始录音、本地自动转写、用户确认发送，并在会话中提供可回听的语音条。

目标宿主版本：DSH `0.2.1-rc.2`。已在隔离宿主完成录音、真实 SenseVoice 转写、附件提交和回听验证；Chromium / WebKit 自动化通过。实际 iPhone 麦克风、后台切换及播放仍待真机验收。

## 安装与使用

需要已安装的 DSH Web 和 Node.js 22.19 或更新版本。在本仓库包含插件实现的 checkout 中：

```sh
npm ci
npm run build
dsh plugin --profile web add /absolute/path/to/dsh-voice-message
```

用实际 checkout 的绝对路径替换示例路径，随后按宿主的正常流程重新加载该 profile。本项目不会修改 DSH 安装文件。

组合包启用本插件和宿主已有的 Speech / SenseVoice 服务，不加载原语音输入法 UI。首次打开输入框旁的“语音”，选择下载来源，点击“下载并准备本地转写”。模型准备是显式操作，初次需要下载资源。

点击“开始录音”，停止后等待转写，再点击“发送语音”。支持取消；重录采用取消后重新录制。单条录音上限 120 秒，首版不提供转写校对。

- 本地 ASR 指在 DSH Host 上推理，远程浏览器仍需连接 Host；冷启动和长录音不保证三秒内完成。
- 原始录音保持不变，仅副本被解码、重采样为 16 kHz 单声道 PCM16 WAV 供 ASR 使用。
- 空转写会明确标记；转写失败时保留录音，可重试或显式选择“仅发送原音”。
- 已发送消息提供播放、暂停、进度跳转、时长与转写查看。浏览器按需回取原音并用 Web Audio 解码播放，避免录音 WebM 缺少时长/索引导致的原生进度异常。
- 切会话或隐藏页面会终止正在进行的录音，迟到的权限和转写结果不会重新发起发送。

## 实现边界

- 只用 DSH 公开插件接口，不改 core、不注入私有实现、不伪造会话事件。
- v1 使用 `file` 和独立 `text` block；音频不会原生投递给模型，也不声称模型已经听过原音。
- 不依赖、探测或调用其他音频分析插件。消息只提示 agent 根据当前可用能力按需辅助理解音频，不写死插件或工具名。
- 通过公开用户消息节点包装 factory 调用，普通内容委托原渲染器；不直接替换同名 factory。自带私有注入、子 slot 或 store 的其他自定义用户消息渲染器不在已验证组合范围内。
- 回取走宿主认证后的 owner Fetch 路由，并校验所选会话确实引用该语音附件。原音按宿主附件存储语义留存，插件不另做定期清理，也不承诺永久保存。
- 不做 TTS、唤醒词、流式字幕、自动发送或后台声音分析。

## 开发验证

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm run build
npm test
```

自动化默认静音输出，使用合成麦克风与模拟 Speech 响应，覆盖真实浏览器录音编码、WAV 预处理、播放器、取消、重试和会话隔离；真实宿主与本地模型验证另行执行，不能用自动化模拟结果替代实际设备验收。

接口依据与阶段验收见 [HANDOFF.md](HANDOFF.md)，开发纪律见 [AGENTS.md](AGENTS.md)。
